## 4 pillars

Abstraction
Definition: Hides unnecessary implementation details and shows only essential features.
Purpose: Reduces complexity and improves usability.
Example: When driving a car, you use the steering wheel, brake, and accelerator without knowing how the engine works.


Encapsulation
Definition: Wraps data (variables) and methods (functions) into a single unit (class) and restricts direct access to the data.
Purpose: Protects data from unauthorized access and modification.
Example: A bank account class keeps the balance private and allows access only through methods like deposit() and withdraw().



Inheritance
Definition: Allows one class (child/subclass) to acquire the properties and methods of another class (parent/superclass).
Purpose: Promotes code reuse and establishes relationships between classes.
Example: A Car class inherits features from a Vehicle class, such as start() and stop().



.
Polymorphism
Definition: Allows the same method or interface to perform different actions depending on the object.
Purpose: Increases flexibility and extensibility.
Example: A draw() method behaves differently for Circle, Rectangle, and Triangle objects.
